## About The Project

An advanced server-side aimbot solution with customizable snap and silent targeting modes. Features extensive configuration options including target prediction algorithms, hitbox preferences, and weighted scoring system for optimal target selection. Created as an experimental project to explore CS2 server-side mechanics.

The windows signature is untested but theoritically I found the correct one.

### Commands

Players without permission won't see any response from these commands.
Also if you want to use it properly, bind it on your mouse4 and mouse5 for easy toggles.

css_aim - Toggles snap mode - Instant aim to targeted hitbox group
css_silentaim - Toggles silent aim mode - Drags the aim with the given speed to the target hitbox group

### Dependencies

To use this server addon, you'll need the following dependencies installed:

- [**CounterStrikeSharp**](https://github.com/roflmuffin/CounterStrikeSharp/releases): CounterStrikeSharp allows you to write server plugins in C# for Counter-Strike 2/Source2/CS2.
